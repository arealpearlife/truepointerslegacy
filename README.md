# Legacy

Foundation for the True Pointers Legacy application.

## Current phase

This repository currently contains project organization, security boundaries, and build-readiness documentation. Point-of-sale features have not been started.

## Structure

- `app/` — application source code when implementation begins
- `assets/` — approved brand assets and color palettes
- `docs/` — setup, decisions, repairs, pricing, and operating documentation
- `data/customers/` — local customer-data staging; contents are excluded from Git
- `private/` — confidential project material; contents are excluded from Git

Start with [`docs/FOUNDATION.md`](docs/FOUNDATION.md).
